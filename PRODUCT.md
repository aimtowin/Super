# Product

## Register

product

## Users

Creative professionals organising local images, video, audio and models in a desktop workspace. See README.md and docs/product-brief.md.

## Product Purpose

Super Lib is a local-first visual asset workspace. Browsing, organising and previewing assets should remain responsive while background work runs.

## Brand Personality

Quiet, precise, practical. Existing Super Lib controls and its blue accent are the visual reference.

## Anti-references

User feedback rejects oversized update windows, white native title bars, decorative slogans and buttons that look like highlighted text. The user explicitly requests rectangular translucent frosted-glass update surfaces.

## Design Principles

- Make progress and the next action obvious.
- Keep typography and controls consistent with the workspace.
- Show completion before asking the user to launch the updated application.
- Use decoration sparingly and preserve space for long status messages.

## Accessibility & Inclusion

Implementation baseline: readable contrast, keyboard-operable actions, visible focus and reduced-motion support. Respect Windows scaling. No additional user-specific accessibility requirements have been stated.
