# 图片素材生成

Super 2.4.8+ 拓展。提供一个同风格的图片素材生成工作台。

- 选择上游渠道：“原生”（12 号渠道，约 ¥0.1/张）或“超分”（13 号渠道，约 ¥0.02/张）。
- 左侧设置画面描述、尺寸（16 倍数，256–4096）与生成数量（1–4 张）。
- 右侧展示本次结果与最近生成历史，支持下载原图。
- 服务器接收上游图片后先通知客户端，再由客户端流式下载并显示真实字节数/百分比；下载完成后才显示图片。
- 安装无需鉴权；生成和读取历史需要访问密码，密码只保存在当前页面内存中。
- 工作台通过 Super 生图代理连接上游网关，上游密钥不进入插件包或浏览器页面。
- 模型固定为 `gpt-image-2.6`。

## 实现边界

Super 2.4.9 起，拓展更新由服务器目录独立检查与安装，不需要随软件本体发版；只有最低宿主版本变化时才需要更新软件。

插件运行时为非受限模式，仅用于向 Super 生图代理发起 HTTPS 请求；页面本身是 sandboxed iframe，
不直接接触上游密钥。代理服务位于 `https://43.142.93.106/image-studio-api/`，按密码校验并限流。
