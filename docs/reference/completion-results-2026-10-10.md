## 收尾中实际发现并修复的问题

1. 同步阶段面对已按策略移除的索引行仍应用元数据：现在跳过该本地缺失目标，保留当前远端版本；不把索引缺失转成删除。
2. 链接资产元数据被不正确限制为托管资产：已纳入链接资产，仍遵守忽略/离线/源保护。
3. 批次重新链接后全库刷新清掉尚未匹配的历史缺失行：只刷新成功恢复的目标，未匹配项可继续处理。
4. 迁移 51 失败后重试的建表冲突：仅新迁移使用 IF NOT EXISTS，历史迁移校验不变。
5. 工作区预览先加载小占位图时消耗原图缩放书签：只有全尺寸匹配后恢复书签，明确“适合窗口”仍可重置。
6. 关闭查看器后旧延迟焦点恢复抢走新选择，或取消恢复留下隐藏画布：新选择取消旧帧；非浏览恢复路径即使查看器已清空也清理标志。
7. 字体预览误入无对应生成器的栅格缩略图队列：能力判断与入队同时排除字体，保留源预览。
8. UTF-8 转码成功被显示成红色错误：改为独立完成状态。
9. 发布器上传后未逐文件复算远端哈希：新增 staging SHA-256 校验后才提升；已存在版本目录拒绝覆盖。
10. 创建合集异步返回覆盖用户刚切回的「所有资产」：导航入口先保留代际，迟到创建结果只更新当前库目录，不覆盖更新的导航意图。
11. 本地插件安装错误只在 GitHub 安装视图显示，造成点击后没有反馈：在本地选择界面加入可见错误，保留 Main 的版本兼容拒绝，并验收拒绝后修正包可继续安装。
12. 批量目录失败使用未本地化的 Worker 原文：接入与单目录相同的公共错误映射，成功项及原始错误日志仍保留。
13. 单资产乐观锁冲突同时显示通用「读取失败」和版本冲突两个提示：保留版本冲突及显式刷新入口，去掉误导的重复读取失败提示；真正的多资产读取失败仍显示失败 ID 和重试。真实 Inspector 新回归 5 项通过。
14. 冲突后显式刷新仍被普通刷新草稿保护拦住：只在已确认的冲突恢复时采用最新元数据，且仅替换点击时的旧草稿；请求期间的新输入和普通后台刷新草稿仍受保护。实际 hook 增加两项回归，与相关 Inspector 共 30 项通过。
15. 快速关闭字体预览并点击新卡片后，空格可能先于选择状态提交：失败诊断捕获新 GIF 卡片已聚焦、选择仍为空。键盘入口改为同提交更新监听，并优先解析聚焦卡片；不打开缺失/已删除/移出范围的旧目标。新增纯边界测试 5 项，键盘/工作区相关共 14 项通过。移除临时诊断后，组合预览及滚动框选各连续五次通过（10 项，59.4 秒）。框选夹具等待虚拟列表布局提交、轮询精确最终集合，原几何与精确 ID 断言保留。
