# Documentation assets

This directory contains visual assets used by the user and developer documentation.

- `ui/live-2.2.8/` contains screenshots captured from the running Super Lib application; see its [capture notes](ui/live-2.2.8/README.md).
- `ui/super-workspace-2.2.8.png` is the current workspace overview; `ui/super-Logo.png` is the product logo.
- Other screenshots are legacy evidence, not automatically current UI references. Check both the layout and product name before reusing them.
- `ui/sync-settings.png`, `ui/library-sync.png`, and `ui/open-sync-library.png` have been withdrawn from the current WebDAV guide because they contain outdated branding. The guide now uses newly captured equivalents under `ui/live-2.2.8/`. Keep the old files as historical assets, not tutorial illustrations.
- `ui/extension.png` actually depicts the legacy browser capture menu, not the application plugin manager. Its previous use in the plugin guide was incorrect; the guide now uses `ui/live-2.2.8/plugin-settings.png`.
- `diagrams/source/` contains editable Mermaid diagram sources.

Do not publish credentials or private user data in screenshots. Replace outdated screenshots with verified captures rather than treating an “older reference” label as sufficient.

The remaining legacy user-guide illustrations have also been replaced or withdrawn. See the [screenshot audit](ui/screenshot-audit-2.2.8.md) for the per-file mapping and capture limits.
