# WebDAV 云同步

> 文档核对：Super Lib v2.3.21（2026-10-13），依据当前源码及既有[成品验收记录](../releases/v2.3.21-validation.md)。本轮未重新运行软件或外部服务；配图保留实际拍摄版本。

Super Lib 支持通过 WebDAV 服务器在多台电脑之间同步资源库。全局配置服务器、每个资源库单独绑定，之后双向自动同步：本地变更上传、云端变更拉取。

下方配图来自 2.3.17 的隔离演示实例，展示尚未配置服务器时的入口，不代表已完成同步测试，也不重标为当前 2.3.21 成品。同步会传播修改与删除，不等同于独立备份；首次配置请先备份资源库，并用小型测试库验证设备间的同步结果。

## 同步概览

- 在**主菜单 → 设置 → 同步**里配置一个或多个 WebDAV 服务器；每个资源库单独绑定服务器与远端文件夹。
- 同步是双向的：本地导入、修改或删除资产会自动上传；云端变化会自动拉取到本地。
- 自动同步按库开启：保存绑定后立即同步一次，之后按设置的轮询间隔检查云端变化；本地资产变更约 10 秒后自动上传。
- 同步进行中或完成时，右下角会出现 toast 提示；左下角资源库卡片内显示连接状态图标（绿色链接 = 自动同步开启，灰色断开 = 未开启，悬停可见说明）。

## 配置 WebDAV 服务器（全局设置）

打开「主菜单 → 设置 → 同步」，添加同步服务器；「同步」与「常规」是并列的设置分类：

- **服务器地址**：填写 NAS 或共享目录的 WebDAV 路径，例如 `https://nas.local/dav/share/`。建议明确使用 `https://`；省略协议会自动补全 `http://`，HTTP 不加密网络传输。
- **用户名 / 密码**：服务器凭据。密码经系统安全存储加密保存（macOS 钥匙串 / Windows DPAPI），不会明文落盘。
- **允许自签名证书**：仅在确认服务器可信时开启。该选项放宽 TLS 证书校验，不会让 HTTP 传输变成加密连接。
- 保存后可测试连接；连接失败会给出可读原因（地址无效、DNS、TLS、认证等）。

## 绑定资源库（资源库设置）

打开「资源库设置」→「同步」：

- **同步状态**：显示未同步 / 同步中 / 上次同步时间。
- **服务器**：选择该资源库绑定的服务器；切换时自动测试连接。
- **同步文件夹名**：远端目录名，默认与资源库同名。最终远端位置为 `服务器地址/同步文件夹名称/`。
- **自动同步**：开启后本地变更自动上传、云端变化自动拉取。
- **轮询间隔（秒）**：云端变化检查频率，默认 5 秒。**资源库较大时建议填写更长的轮询时间**，避免频繁检查拖慢网络与磁盘。
- **保存**：保存绑定；开启自动同步时会立即触发一次同步。

![当前资源库同步设置；未绑定或开启同步](../assets/ui/live-2.3.17/library-sync.png)

## 同步行为

- 首次连接空远端目录时会上传本库的资产、元数据与清单；连接已有远端目录时会比较双方状态，可能包含下载与冲突处理。后续同步主要传输变化内容。
- 两台设备修改同一文件时，输家版本会保存为「名称 (conflict-…)」的冲突副本，不会静默覆盖。
- 自动同步与手动同步互斥；后台自动同步失败会记录日志，手动操作失败则查看界面提示。

## 打开同步资源库

「打开资源库」→「打开同步资源库…」：

1. 选择已配置的服务器；
2. 面板列出该服务器上的同步库（按远端清单识别，可跨设备继续使用）；
3. 选择目标保存位置后打开，远端内容下载到本地。

服务器需要支持 WebDAV 目录和文件操作，包括 PROPFIND、MKCOL、GET、PUT、DELETE；连接测试还会检查 MOVE 等能力。仅支持普通 HTTP 下载的地址无法替代 WebDAV 服务器。

![打开同步资源库的菜单入口；需先配置服务器](../assets/ui/live-2.3.17/21-library-menu.png)

## 2.3.18 的元数据、缺失与取消处理

首次启用按下面顺序操作；验证结束后再把同样的绑定用于重要库。

```mermaid
flowchart LR
  A[备份并建立小测试库] --> B[配置服务器并测试连接]
  B --> C[A 设备绑定空远端目录]
  C --> D[B 打开同步库并核对文件与元数据]
  D --> E[检查双端修改、取消重试与离线源]
  E --> F[通过后启用正式库自动同步]
```

人工元数据和 AI 结果使用独立版本，以共同基线、当前本地及远端状态进行三路合并；提交时再次检查版本，冲突不应静默覆盖。取消同步会停止后续可取消步骤，已经提交的服务器写入不因取消自动回滚；重新同步前检查两端状态。

链接路径及元数据参与同步，但外部链接源文件并不会因此变成完整托管上传。另一设备需要可访问的源目录，并按实际路径重新链接。暂时缺失/离线源不自动等于删除；明确删除意图另行持久化。托管资产的明确删除仍会传播。

建议先备份，再用小库完成 A 导入→B 下载、双方分别改人工/AI 字段、取消后重试、源目录离线及显式删除这几种操作。当前已有本地/Mock 双设备验证，尚未覆盖所有真实 WebDAV/NAS 多写者场景，详见[当前验收缺口](../reference/known-issues-2.3.18.md)。
