# Appearance

> Documentation reviewed for Super Lib v2.3.21 on 2026-10-13 against current source and existing [packaged acceptance evidence](../releases/v2.3.21-validation.md). This review did not rerun the application or external integrations; screenshots retain their actual capture versions.

[简体中文](appearance.md) · [User guide](README.en.md)

Open **Main menu → Settings → Appearance**. Changes take effect immediately. The screenshots below show the Chinese interface.

## Theme and color mode

The three circular controls select light, dark, or system mode. The Super, VS Code, and Soft cards select the theme style; expand theme-color settings for further color adjustments.

![Dark appearance in the same isolated instance](../assets/ui/live-2.3.17/31-dark-theme.png)

![The same instance switched to light mode](../assets/ui/live-2.3.17/settings-appearance.png)

## Background

Expand the application-background section to preview the image and access image selection and opacity controls. If a detailed background makes filenames or toolbar labels difficult to read, reduce its visibility.

![Expanded background settings](../assets/ui/live-2.3.17/32-background.png)

## Text size and depth

- Text-size levels `1`–`4` affect Super Lib text only, not Windows or other applications.
- Elevation controls adjust shadows between panels.
- Scroll down for context-menu acrylic settings, which control menu transparency and blur.

![Text size and depth settings](../assets/ui/live-2.3.17/settings-appearance-details.png)

These captures use independent demo preferences, not a real user's configuration.
