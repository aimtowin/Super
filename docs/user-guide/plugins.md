# 拓展功能

> 文档核对：2026-11-17。安装通道已改为服务器目录；GitHub 与本地安装入口不再对用户开放。

拓展可以为 Super 增加新的工具、菜单或工作流程。拓展不属于资源库中的普通资产，安装后可以随时启用或停用。

## 安装拓展

1. 打开左侧导航「标签管理」下方的「拓展」，点击安装；也可以从「设置」→「拓展」进入。
2. 选择「从服务器安装」。
3. Super 会读取服务器拓展目录，只显示与当前版本和平台兼容的拓展。
4. 选择安装到「全局」或当前资源库。全局拓展可用于所有资源库；资源库拓展只在当前资源库中使用。

安装完成后，拓展会出现在列表中。首次使用前按界面提示启用并确认信任；资源库拓展在每台设备首次启用时都需要单独信任。

## 首个拓展：无限画布

- 在查看器中，悬浮预览按钮右侧新增“无限画布”按钮。
- 点击后当前资产在独立小窗中打开，主界面保持可见，可以继续浏览。
- 关闭小窗不会把主窗口恢复到前台；默认悬浮预览行为不变。
- 安装完成后立即显示三步引导；按「下一步」浏览，最后点「开始使用」，之后不再重复弹出。
- 同一张图片再次点击不会重复打开多个小窗，而是聚焦已经打开的那个小窗；不同图片仍可同时打开多个小窗。

## 图片素材生成

安装“图片素材生成”后，左侧导航会出现同名入口。打开工作台并输入访问密码后，可以：

- 选择上游渠道：“原生”约 ¥0.1/张，“超分”约 ¥0.02/张；
- 输入画面描述；
- 选择 256–4096 之间、宽高为 16 倍数的尺寸；
- 一次生成 1–4 张；
- 查看最近生成历史，预览或下载原图。生成完成后先显示“服务器已接收”，再显示真实下载字节数与百分比，不再只停留在“正在读取”。

模型固定为 `gpt-image-2.6`。上游密钥保存在服务器，不进入拓展包；密码只保存在当前工作台页面内存中。生图请求失败不会自动重试，避免重复扣费。

Super 2.4.9 起，拓展更新不依赖软件本体：打开「设置 → 拓展」时会检查服务器目录，默认自动安装更高版本，并保留原来的启用/信任状态；也可以关闭自动更新或手动点击「检查更新」。只有拓展声明的最低 Super 版本高于当前软件版本时，才需要先更新软件本体。

## 启用和停用

- 在拓展卡片上打开「启用」即可使用。
- 第一次启用资源库拓展时，Super 会用应用内确认框询问是否信任它；只有确认来源可靠时才选择信任。
- 暂时不用时关闭「启用」，需要时再打开。
- 修改拓展设置后可以点击「重载」，不必重启 Super。

如果同一个拓展同时安装了全局版和资源库版，列表会提示当前使用的版本，可以在那里切换或停用。

## 更新和卸载

服务器目录中的拓展由服务器目录统一提供兼容版本；当前版本不提供 GitHub 更新通道。

卸载拓展不会删除它可能保存的个人设置。如果以后重新安装同一个拓展，希望保留原来的配置，可以直接重新安装；若拓展提供了自己的清理入口，优先使用该入口。

## 遇到问题

如果拓展没有出现在列表中、启用后没有反应，先检查是否正确安装并启用，再重新打开设置。仍然无法使用时，请联系维护者，并附上 Super 版本、操作系统和拓展名称；不要在反馈中公开 API Key 或其他隐私信息。

开发者请阅读[扩展作者手册](../manual/README.md)。
