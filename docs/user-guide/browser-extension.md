# 浏览器扩展状态

[使用手册](README.md) · [English](browser-extension.en.md)

浏览器扩展目前不作为 Super Lib 的可用用户功能提供。`v2.2.8` Release 没有可供用户安装的扩展附件，也未完成当前发行版的实际可用性验证。

此前的安装、右键保存和拖拽采集说明已撤下，请不要再按旧教程寻找扩展 ZIP 或 Firefox XPI。源码中存在扩展实现，不等于已发布可用产品；桌面安装包和增量更新 ZIP 也不是浏览器扩展。

## 现在如何导入网页素材

在来源网站允许且你有权保存的前提下，先使用浏览器将文件下载到本机，再在 Super Lib 中使用「主菜单 → 文件 → 导入文件」，或将本地文件拖入应用。详见[快速上手](quick-start.md)。

本页仅为兼容旧链接保留，不再列入功能导航。只有提供可下载扩展包并完成安装、连接和保存流程验证后，才恢复相应教程。
