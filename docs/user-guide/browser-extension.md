# 浏览器扩展

> 适用版本：Super Lib v2.2.8；安装包可用性以发行附件为准。

把网页图片或视频保存到 Super 资源库，支持**右键保存**和**拖拽保存**。支持 Chrome / Edge（Chromium）与 Firefox。

媒体由**浏览器侧下载**（按请求携带 Cookie 与页面 Referer）再上传到本机 Super。能否保存取决于原网站的访问权限和下载响应。Super 需运行且已打开资源库，扩展通过本机 `127.0.0.1` 连接它。

## 安装

> 当前 `v2.2.8` GitHub Release 未附带扩展 ZIP 或 Firefox XPI。下文适用于已取得项目扩展包的用户；请检查[发布附件](https://github.com/aimtowin/Super/releases)。桌面安装包或增量 ZIP 不能当作扩展安装。Firefox 持久安装需要已签名的 XPI。

### Chrome / Edge

1. 获取 `super-extension-<版本>.zip`，解压到固定文件夹（例如「文档/Super-extension」），文件夹内需直接包含 `manifest.json`。
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压出的文件夹。

### Firefox

1. 获取 `super-extension-firefox-<版本>-signed.xpi`。
2. 打开 `about:addons` → 齿轮图标 →「从文件安装附加组件…」→ 选择下载的 `.xpi`。
3. 安装后**重启 Firefox 仍然生效**，与商店安装一致。

### 更新

- **Chrome / Edge**：获取新版本 zip → 解压覆盖 → 在 `chrome://extensions` 扩展卡片上点「刷新」（或移除后重新加载）。
- **Firefox**：获取新版本 `.xpi` → 重复安装步骤，覆盖旧版本。

## 使用

1. 启动 Super 并打开一个资源库。
2. 扩展工具栏图标在已连接时会变为**彩色**；未连接时保持**灰色**。
3. **右键保存**：在网页图片或视频上右键 →「保存到 Super」→ 选择目标文件夹（最近保存/浏览 → 分割线 → 全部一级目录，子文件夹可逐级展开）。
4. **拖拽保存**：拖拽图片时自动展开树状保存菜单——悬停有子文件夹的目录右侧 `›` 进入下一级；左侧 `‹` 返回；面板外松开或 `Esc` 退出。
5. 保存过程中页面会出现「正在保存到 Super」气泡反馈。

### 选项页

右键扩展图标 → 选项，可开关：

- 通知（保存结果系统通知）
- 保存后聚焦 Super 应用
- 保存后在资源库中显示该资产
- 拖拽网页图片/视频时的树状保存菜单

## 常见问题

**保存时提示「无法连接 Super」**

确认 Super 桌面应用已启动并打开了资源库。扩展图标变灰 = 未连接；变彩 = 已连接。

**保存时提示「forbidden origin」（403）**

确认桌面应用与扩展包相互兼容，记录浏览器版本、扩展版本与错误提示；不要只按旧的版本号门槛判断。持续失败时提交反馈。

**保存后库里没看到图片**

检查选项页「保存后在资源库中显示该资产」是否开启，并确认保存时选择的目标文件夹。

**Firefox 安装时提示「此附加组件无法安装，因为它未通过验证」**

可能是签名、文件完整性或浏览器兼容性问题。请核对下载文件，使用项目提供的已签名 XPI；若发布页没有对应附件，则该页当前不提供可持久安装的 Firefox 包。

**扩展能访问所有网站吗？安全吗？**

扩展需要访问目标网页以识别和下载媒体。下载会请求媒体来源网站，写入资源库通过本机 Super 接口完成。请核对扩展来源及浏览器显示的权限说明。

## 隐私

- 下载请求可能携带来源网站需要的 Cookie 与 Referer；这不等同于完全离线操作。
- 保存动作由你主动发起；媒体文件直接上传到你本机的 Super 应用。
- 仅保存的记录（最近使用的文件夹）存放在浏览器本地 `storage` 中。
