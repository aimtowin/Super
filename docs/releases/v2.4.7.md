# Super Lib 2.4.7

日期：2026-11-17（Asia/Shanghai）。平台：Windows x64。

本版修复 2.4.6 拓展体系的界面与交互问题。

## 主要改动

- **侧栏入口**：新增“拓展”入口，位于“标签管理”下方，可直接打开拓展设置。
- **窄窗口排版**：修复部分窗口尺寸下“安装拓展”“从服务器安装/安装”等按钮和文案被挤压换行的问题。
- **主题化确认**：启用需要信任的资源库拓展时，改用应用内确认框，不再使用系统原生 `confirm`。
- **无限画布去重**：同一资源库的同一资产不会重复打开多个独立小窗；再次点击会聚焦已打开的小窗。不同资产仍可同时打开多个小窗。
- **即时分步引导**：安装“无限画布”成功后立即显示三步引导（返回 / 下一步 / 开始使用），不再等到首次点击按钮才出现。
- 保留默认悬浮预览行为：仍会最小化主窗口，关闭后恢复；无限画布关闭独立小窗仍不恢复主窗口。

## 升级方式

- 2.4.0 / 2.4.1 / 2.4.2 / 2.4.4 / 2.4.5 / 2.4.6 客户端均可增量升级。
- 2.3.21 及更早版本仍需手动安装一次 `SuperSetup.exe`。
