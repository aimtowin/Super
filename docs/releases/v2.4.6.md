# Super Lib 2.4.6

日期：2026-11-17（Asia/Shanghai）。平台：Windows x64。

本版建立服务器拓展体系，并交付首个拓展“无限画布”。

## 主要改动

- **拓展命名**：用户界面中的“插件”统一改为“拓展”；英文使用 Extensions。
- **安装通道**：移除 GitHub 与本地安装/更新入口，改为 Super 服务器拓展目录：
  - `https://43.142.93.106/downloads/super/plugins/latest.json`
  - 客户端只接受固定 HTTPS origin、同源资产路径，并校验声明大小与 SHA-256。
- **首个拓展：无限画布**（`com.super.infinite-canvas`）
  - 查看器“悬浮预览”按钮右侧新增“无限画布”按钮。
  - 独立小窗预览，主窗口保持可见且不最小化。
  - 关闭小窗不恢复或聚焦主窗口；默认悬浮预览行为不变。
  - 支持同时打开多个独立小窗。
  - 首次使用显示一次性宿主风格引导。
- 继续包含 2.4.5 的窗口全屏/最大化记忆与 6 档字体（默认第 4 档）。

## 升级方式

- 2.4.0 / 2.4.1 / 2.4.2 / 2.4.4 / 2.4.5 客户端均可增量升级。
- 2.3.21 及更早版本仍需手动安装一次 `SuperSetup.exe`。
