# v2.3.10 验证记录

> 2026-09-28 用户反馈更正：已发布版的菜单 Portal 改动仅解决 DOM 层叠，仍遗漏 Electron 原生标题栏拖拽区域。原 Playwright 点击绕过 Windows 非客户区命中测试，不能证明实际鼠标可点击。新增 `WM_NCHITTEST` 回归在原构建中复现 HTCAPTION=2；本地为 `.context-menu` 增加 `-webkit-app-region: no-drag` 后返回 HTCLIENT=1，关闭菜单后恢复 HTCAPTION=2，图标设置动作通过。此补充修复尚未打包发布，不属于原 v2.3.10 附件。

## 变更范围

- 文本格式筛选在 Renderer 到 Worker 的进程边界保持紧凑 token，仅由 Worker 在本地 SQL 查询阶段展开。
- 格式筛选允许当前产品公开的完整格式分组组合；非格式分类筛选继续维持 32 项安全上限。
- 纳入侧栏图标菜单命名与顶部重叠右键菜单的 DOM 层叠调整；后者的原生拖拽遗漏见顶部更正。
