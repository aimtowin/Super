# Super Lib v2.3.14

## 导入稳定性

- 修复确认导入时可重复提交、随后误报“待处理的导入已失效”的问题。处理中锁定确认、取消和选项，Escape 不再取消正在执行的导入。
- 同一导入的重复确认复用正在执行或近期完成的结果，避免重复复制；失败重试保留真实原因。
- 普通托管文件导入的确认应用阶段增加事务外分段调度，避免整个批次持续独占后台；关闭资源库等待正在执行的导入完成。
- 合并资产变化触发的历史状态查询，避免大型导入产生大量排队请求和超时。

## 说明

- 不改变中文、方括号等合法文件名的支持。
- 大文件单次处理、数据库事务、Eagle/Billfish 专用批量通道仍存在同步工作，不宣称所有导入路径完全异步。
- 若此前出现失效提示，请先查看已导入资产，再决定是否重新选择，避免人为重复导入。
