# Super Lib 2.3.21

2026-10-12（Asia/Shanghai）。文件夹切换与中央画布优先修复版本；实际发行状态见[验收记录](v2.3.21-validation.md)。

## 本次修复

- 切换文件夹时先显示中央资产卡片，右侧统计和封面后续独立读取，不再争抢首屏的整库目录查询。
- 首屏或子目录尚未返回时沿用加载动画。只有查询成功且确实没有资产/子目录时才显示导入提示；读取失败不伪装为空目录。
- Inspector 改为目标目录/链接根索引读取，去掉整库目录枚举及封面查询不使用的精确计数，保留递归数量、离线信息、Unicode 路径和空链接目录身份校验。
- 修复空筛选重置触发重复首屏请求、旧 debounce 覆盖新目录，以及查询替代导航后遗留 loading 状态。
- 保留同范围后台刷新时可用卡片，隔离快速 A→B→A 切换和同 ID 重开后的旧结果；筛选、合集、封面、递归和全屏后台刷新回归继续保留。

详细复现和源码证据见[画布优先记录](../plans/2026-10-12-canvas-first-folder-navigation.md)。不以隔离测试推断所有磁盘上的固定加载时间或整体速度百分比。

## 边界

Windows x64 成品按验收记录发布。没有重建用户索引或修改用户库；旧标签、附件、不可变基线不替换。K01 自动化 Console 运行时依赖问题仍开放。macOS、真实 NAS 长时压力和 WebDAV 多写者不由本轮局部回归替代。MIT 开源不变；账号、官方插件目录与 ECS 整机迁移仍暂停。
