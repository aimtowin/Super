# Super Lib v2.3.16

## 筛选交互

- “包含／排除”固定在筛选面板顶部，滚动时仍可操作；采用统一、可通过键盘操作的模式控件。
- 已生效的排除条件明确显示“排除 格式 · png, jpg”等摘要，面板选项、按钮和摘要状态保持一致。
- 修复形状预设多选无法排除，以及“更多”面板误显示排除状态的问题。
- 明确普通点击和 Shift 多选的提示，将资产反选命令明确为“反选资产”；保留原有查询语义、组选择和筛选内反选行为。
- 改善深浅主题、滚动、文字缩放与控件对比度。

## 更新体验

- 安装完成后短暂显示“更新已完成”，自动打开 Super Lib 并关闭更新小窗口，无须再次点击启动。
- 更新窗口更加紧凑，突出版本、状态和蓝色进度，正常流程不再显示无效启动按钮。
- 启动失败时明确说明新版本已安装，提供重试打开和关闭操作；避免自动重试循环和重复启动。
- 全量和增量更新使用相同流程，保留原用户身份启动及更新完成通知。

## 兼容性

- Windows x64；不改变资源库结构、下载完整性校验或用户数据处理。
- 原生更新窗口的改进包含在本版安装器中，升级到本版即可使用。
