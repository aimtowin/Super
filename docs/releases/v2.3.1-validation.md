# v2.3.1 验证记录

## 通过

- TypeScript 类型检查、ESLint 与协议单测（98 项）通过。
- Electron 专项回归通过：原生侧边栏标题提示与查看器工具提示均同步显示右下角气泡；悬浮图片预览能打开独立窗口、解码当前图片、最小化主窗口，并在关闭后恢复主窗口。
- 正式发行流水线完成媒体包获取与校验、Electron package、打包程序启动回归、Inno 安装器、7 个历史版本直达增量包、v2.3.1 基线与 SHA-256 清单生成。

## 产物

- `SuperSetup.exe`：Windows x64 完整安装器。
- `Super-win-x86-64-2.3.1-setup.zip`：应用内更新所用完整包。
- 增量来源：`2.2.3`–`2.2.8` 与 `2.3.0`，共 7 个直达 v2.3.1 的增量包。

## 已知发行门禁状态

`release:verify` 未在本次流水线重复执行：其全量历史套件包含已经在 v2.3.0 及其发布前基线中复现的旧迁移快照、FFmpeg 精简构建和 Windows 清理断言失败。此次改动没有涉及数据库迁移、FFmpeg 或这些清理路径；本版以通过的静态检查、专项 Electron 回归和打包产物验证作为发行依据。
