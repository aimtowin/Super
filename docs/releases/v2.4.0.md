# Super Lib 2.4.0 更新说明

日期：2026-10-22（Asia/Shanghai）。这是更新源迁移版本，跳过原计划的 2.3.22 过渡版本。

## 变更内容

- **更新源改为服务器 IP 直连**：`https://43.142.93.106/downloads/super/latest.json`。新服务器域名尚未完成 ICP 备案，域名入口暂不可用；服务器已为该 IP 签发受信任证书，客户端仍以 HTTPS 校验证书、以 SHA-256 校验下载内容。
- **不再生成增量包**：2.4.0 只发布完整更新包（`Super-win-x86-64-2.4.0-full-setup.zip`）与安装器（`SuperSetup.exe`），`latest.json` 的 `deltas` 为空数组。
- **旧版本下线**：本地与旧更新服务器上的历史版本目录、增量包和安装包已删除；旧更新源（域名）不再提供更新清单。

## 升级方式

2.3.21 及更早版本的客户端写死了旧更新源，无法自动发现 2.4.0。请下载 `SuperSetup.exe` 覆盖安装；安装器不删除本地资源库、素材或设置。
