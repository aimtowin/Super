# Super Lib 2.4.5

日期：2026-11-17（Asia/Shanghai）。平台：Windows x64。

本版修复窗口状态记忆遗漏，并扩展应用字体档位。

## 主要改动

- **窗口状态记忆**：修复主窗口全屏状态未保存的问题。全屏、最大化、普通拖拽尺寸/位置现在都会写入窗口状态，并在下次启动恢复；最小化仍不覆盖已保存的位置。
- **字体档位**：应用字体大小从 4 档扩展到 6 档，新增 5、6 档（1.3、1.4 倍）；默认档位改为第 4 档（1.2 倍）。
- **设置外观页**：滑块范围同步为 1 至 6，修正字号滑块的无障碍读数，4 档文案从“最大”调整为“大”，新增“更大/最大”。

## 升级方式

- **2.4.0 / 2.4.1 / 2.4.2 / 2.4.4 客户端**：可从更新源增量升级，本版提供对应直达增量包。
- **2.3.21 及更早版本**：旧更新源已下线，需手动安装 `SuperSetup.exe` 一次；覆盖安装不删除资源库、素材与设置。

## 验证摘要

- `npm run typecheck`、`npm run lint` 通过。

- 字体设置 E2E 通过：默认第 4 档、滑块 6 档、选择第 6 档后 1.4 倍并持久化。
