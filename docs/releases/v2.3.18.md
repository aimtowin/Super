# Super Lib 2.3.18

## 本次更新

- 文件夹与合集图标：11 类、200 个 Emoji，24 个图形和 8 种颜色；兼容原有图标偏好。子级拖至直接父级可提升到同级或根目录，并支持撤销。
- 颜色与搜索：任意 HEX 颜色、HSL 容差及反向排除；有界搜索历史、逗号多标签，以及 PNG 内嵌生成信息的独立筛选。生成标记不等于 AI 来源鉴定。
- 目录管理：名称过滤、保留祖先、自然排序；基于索引的目录检查器；忽略规则只读预览与显式保存；最多 32 个目录批量创建，部分失败不回滚成功项。
- 独立工作区：最多 6 个会话工作区，分别保留导航、筛选、选择、预览和滚动。共享资料库与后台任务；工作区本身不跨重启保存。
- 媒体预览：JFIF/AVIF 源图、FLV 按需代理；音频嵌入封面与波形开关；有界 GIF 暂停、逐帧；视频 0.25–4 倍速和正逆旋转；图片缩放状态恢复。
- 字体与文本：TTF/OTF/WOFF/WOFF2/TTC 字体预览（TTC 第一字库）；文本折行及编码提示；显式转 UTF-8 保留原字节备份和撤销。
- 安全写回：静态托管图片旋转、翻转默认只显示，只有明确确认后才写回；保留原字节备份，支持撤销/重做及冲突保护。
- 同步与大内容：人工/AI 元数据独立版本、三路合并、冲突副本及取消；RPC 预算与 1 MiB 分块读取，保留原有小文件接口和安全上限。

## 关联修复

修复字体反复入缩略图队列、预览焦点恢复抢走新选择、工作区小占位图消耗原图缩放书签、合集创建覆盖最新导航、本地插件安装错误不可见、批量建目录错误未本地化，以及元数据冲突提示重复和显式刷新仍保留被拒绝草稿的问题。

同步不再因本地索引行缺失覆盖远端元数据，链接资产元数据参与同步；批次重新链接仅刷新成功恢复目标，保留未匹配历史缺失项。仅追加数据库迁移 50/51，历史迁移不改写。

## 升级注意

升级前保留资料库备份。新数据库 schema 不支持用旧版继续写入。同步不是备份；真实 WebDAV 多写者、macOS、NAS 长时压力及真实 AI 供应商不由本轮 Windows 夹具视为验收通过。

本体继续 MIT 开源、免费免账号。账号、社区、官方插件目录和 ECS 迁移仍暂停；此次仅更新已有自动更新源。
