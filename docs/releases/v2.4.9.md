# Super Lib 2.4.9

日期：2026-11-18（Asia/Shanghai）。平台：Windows x64。

本版完善图片素材生成拓展的上游渠道，并让拓展更新脱离软件本体发版。

## 主要改动

- **图片素材生成 1.1.0**
  - 新增“原生”和“超分”两个上游渠道选择。
  - 原生：网关 12 号渠道 `SRAI-Image`，约 ¥0.1/张；服务端使用受控别名 `gpt-image-native`。
  - 超分：网关 13 号渠道 `SRAI-Upscale`，约 ¥0.02/张；使用 `gpt-image-upscale`。
  - 结果与历史记录显示渠道；工作台布局同步调整。
- **拓展独立自动更新**
  - Super 2.4.9 起，打开「设置 → 拓展」会检查服务器目录。
  - 默认自动安装更高版本，并保留原有启用/信任状态。
  - 提供自动更新开关、「检查更新」和「更新全部」。
  - 只有拓展最低宿主版本升高时，才需要更新 Super 本体。
- 服务器目录图片素材生成已升级到 1.1.0；2.4.8 用户可手动更新，2.4.9 起自动更新生效。
- 网关为原生渠道新增仅服务端使用的路由别名；上游密钥仍不进入拓展包或页面。

## 升级方式

- 2.4.0 / 2.4.1 / 2.4.2 / 2.4.4 / 2.4.5 / 2.4.6 / 2.4.7 / 2.4.8 客户端均可增量升级。
- 2.3.21 及更早版本仍需手动安装一次 `SuperSetup.exe`。
