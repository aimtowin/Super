# v2.3.14 验证记录

## 修复与边界

- 依据用户提供的 17:52 会话日志定位重复确认、同步 apply 阻塞及历史状态查询风暴；未持有用户原始素材库，不能声称已在其全部数据上复测。
- 前台同步提交锁及 busy 状态覆盖确认、取消、选项和 Escape；后台同决策确认共享任务/结果，不同决策拒绝。近期结果最多保留 32 项、15 分钟，关闭库清除。
- 普通托管导入共享原有同步实现的生成器步骤，桌面入口在事务外按时间片调度；写租约及心跳覆盖全程，关闭等待实际应用完成。专用 bulk 事务、单文件解析/哈希等仍同步。
- 历史查询由资产事件节流和单请求＋一次尾随刷新共同约束，切换库时忽略旧响应。

## 验证

- 11 个测试文件：123 通过、2 跳过。其中 13 个新增用例覆盖重复确认、错误重放、读请求响应、关闭/过期竞态、11,345 次通知合并、忙碌对话框和 Escape。
- 原样扩大测试仍复现历史 `ENOTDIR` 缺失占位旧用例及其清理 EPERM；最终专项运行排除此已记录旧用例，另一个为原有平台条件跳过。不宣称全量通过。
- TypeScript 主工程与扩展检查通过；修改源码及测试 ESLint 通过。
- Windows x64 构建、运行资源验证及 528 项字体引用验证通过。
- 三项实际成品 E2E 通过：真实 Worker 导入（新增并发两次＋完成后一次确认结果一致）、FTS5 搜索筛选、关闭到托盘。
- 7,992 项文件基线、20 个直达增量包、校验清单及 ECS 发布预检已生成并验证。
