# Super Lib v2.3.9

## 侧栏自定义 Emoji 图标

- 普通文件夹、链接文件夹及其子目录、合集和智能合集，现在支持右键 →「设置 Emoji…」。
- 提供 32 个常用表情，也可输入或粘贴一个 Emoji，支持肤色、旗帜和组合表情。
- 支持预览、取消和恢复默认。设置按资源库及条目保存于本机，重启后保留，不随资源库导出到其他电脑。
- 链接文件夹保留链接及离线状态提示，不改变导航、拖拽和筛选行为。
- 使用紧凑的深浅主题面板，支持键盘操作，不增加图标包或网络依赖。

本版为 Windows x64 发行，安装时请先退出 Super Lib。原有素材与资源库保持不变。
