# Super Lib v2.3.13

改善资产导入的稳定性与后台响应。

- 修复文件在扫描后、复制前更新导致整批导入失败的问题；同一文件的最新稳定内容可正常导入。
- 对复制期间的短暂变化进行有限重试，保留完整性检查；持续变化或文件被替换时安全终止，不导入不完整内容。
- 普通托管导入采用异步暂存复制与流式哈希，分段执行扫描和准备任务，减少后台查询积压及超时。
- 补充导入失败诊断：具体源文件、变化阶段、变化字段与重试次数。
- 完善关闭资源库时的暂存清理，保留自动化导入的确认校验。

中文和方括号文件夹名称已通过回归测试。旧 Billfish 素材库建议使用专用导入入口；普通文件夹导入可能包含仍在更新的隐藏数据库文件。

本版为 Windows x64 发行。
