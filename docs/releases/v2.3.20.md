# Super Lib 2.3.20

2026-10-11（Asia/Shanghai）。侧栏加载回归修复版本；实际发行状态见[验收记录](v2.3.20-validation.md)。

## 本次修复

- 修复恢复非默认排序、搜索或切换浏览范围时，左侧目录、合集、智能合集和右侧库统计长时间为空的问题。全库组织与计数不再被前台画布查询换代误取消。
- 目录和合集按各自成功结果及时显示，不再整批等待最慢的统计请求。单个统计或标签读取失败不丢弃其余成功列表。
- 优先提交导航读取，再补充统计，减少串行 Worker 队列中的等待；不扩大超时、不重建用户库索引。
- 修复筛选页/合集页总数误写为全库资产数量；全库计数使用无筛选范围，画布仍保留用户查询。
- 保留库切换、同 ID 重开、较新刷新和 React 队列更新的过期保护，保留后台突发刷新合并与完整读取租约，防止旧结果覆盖新状态。

## 从 2.3.18 升级

包含 2.3.19 的 Markdown 安全渲染与源码切换、ZIP 只读成员浏览、库内图片文件夹封面、查看器近边工具栏、全屏切图及可逆缺失链接隐藏等能力，详见[原升级说明](v2.3.19.md)。本版不覆盖旧版本发行附件、标签或不可变基线。

## 边界

Windows x64 成品按验收记录发布。普通导入、浏览和查看器无需自动化 Console；原 K01 Console 运行时依赖问题仍开放。macOS 成品、真实 NAS 长时压力和真实 WebDAV 多写者不由本轮局部回归代替。保持 MIT 开源；账号、官方插件目录与 ECS 整机迁移仍暂停。
