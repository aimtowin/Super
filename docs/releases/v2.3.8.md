# Super Lib v2.3.8

## 本版重点

- 保守精简发行包：移除构建后不再使用的原始字体副本和字体生成工具；保留正式字体、许可证、全部界面语言、媒体处理及 PDF / 3D / 插件功能。
- Windows 安装器从约 229.83 MiB 降至 190.15 MiB（减少约 17.26%）；程序文件总大小减少约 45.63 MiB。
- 完整安装器清理旧版本的对应字体依赖目录；增量更新按文件清单清理，不触及用户资源库和自定义素材。
- 上线快速开始引导：首次运行可按步骤创建或打开资源库、导入素材、认识工作区，并选择配置外观和 AI；支持跳过、继续和在“设置 → 常规”中重新查看。已有用户升级不自动弹出引导。

## 更新方式

继续使用现有 ECS 和 GitHub 发行机制，支持历史基线直达当前版的增量包、完整包回退及 SHA-256 校验。ECS 保留最近 5 个完整发行目录，最多保留 20 个增量来源版本。

## 验证范围

已完成静态检查、针对性单元测试及真实安装目录的字体加载、导入、搜索、托盘、快速开始引导、PDF 悬浮预览和 OBJ/FBX 预览验证。

详细数据及既有全量测试限制见 [发行验证记录](v2.3.8-validation.md)。本版不宣称修复既有的全部历史失败用例。
