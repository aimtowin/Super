# Super Lib 2.5.0

日期：2026-11-18（Asia/Shanghai）。平台：Windows x64。

本版修复启动更新提示的可靠性问题，并把图片素材生成的下发改成真实进度页；同时收录维护者开发纪实与开源致谢。

## 主要改动

- **启动更新提示**
  - 启动检查由 12 秒缩短为 4 秒。
  - Preload 缓存“有更新”事件，Renderer 晚挂载也会补发，不再依赖一次性 IPC 抢跑。
  - 启动检查写入状态日志，便于诊断。
- **图片真实下载进度**
  - 服务器收到上游图片后先返回“已接收”。
  - 拓展运行时流式下载图片，工作台显示真实字节数和百分比。
  - 下载完成后才显示图片；旧宿主保留直接图片回退。
  - 图片素材生成服务器目录版本为 1.2.0。
- 保留原生/超分双渠道与拓展服务器目录独立自动更新。
- 文档新增《我如何继续开发 Super Lib》中英文开发纪实、开源致谢和 2.5.0 发行记录。

## 升级方式

- 2.4.0 / 2.4.1 / 2.4.2 / 2.4.4 / 2.4.5 / 2.4.6 / 2.4.7 / 2.4.8 / 2.4.9 客户端均可增量升级。
- 2.3.21 及更早版本仍需手动安装一次 `SuperSetup.exe`。
