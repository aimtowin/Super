# Super Lib v2.3.15

## 性能与响应

- 合并后台任务轮询和资产刷新，避免慢请求重叠或通知造成查询堆积。
- 缩略图缓存按已知资产范围失效；无法确定范围的事件仍完整刷新。
- 导入完成仅读取受影响资产，避免大型资源库的全量摘要查询。
- 侧栏计数和普通浏览索引保留有效缓存；实际资产、标签、合集、AI 已分析状态等变化仍及时失效。
- 后台对账的大文件校验使用异步分块读取，保留取消、文件身份及提交前版本检查。
- 减少分页合并的临时内存分配，不丢弃已加载资产，保持选择和预览操作。

## 稳定性

- 修复分页滚动到底后加载停滞和布局尚未加载完成时尾部资产不显示的问题。
- 缩放时可从紧凑布局恢复已被虚拟化移出界面的资产位置，保留原有画布中心缩放行为。
- 路径祖先临时不可用时保留资产版本和元数据；恢复路径后可以恢复原资产，确认删除仍按原规则处理。
- 切换智能合集时丢弃旧页面请求的过期结果，后台刷新保持全屏预览状态。

## 兼容性与验证范围

- 不升级资源库结构，不改变合法文件名支持、导入恢复和原有通知功能。
- Windows x64 发布；本轮性能数据来自本地测试，不能代表所有 NAS、硬件或大图场景。
- 未宣称所有导入适配器完全异步，也未改为多个 SQLite 写线程。
