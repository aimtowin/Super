# Super Lib 2.3.17

本次更新集中优化异步任务的所有权、刷新合并、元数据读取与发行产物校验，不更换数据库或引入账号门槛。

## 浏览与编辑

- 分页请求绑定浏览会话与查询代次，旧请求完成或清理时不会覆盖新页面，也不会释放新请求的加载占位。
- Inspector 元数据读取共享一个有界调度器：最多四个未结束的原始读取，多选后台读取最多占三槽，主选资产优先。取消界面兴趣不会提前释放仍在执行的请求槽位。
- 多选编辑必须取得完整目标集合，不以读取成功的部分资产替代全部选择；保留未提交描述草稿、人工/AI 来源、并发版本校验与撤销重做。
- 磁盘变化、导入、AI 单项/批量完成及本地删除共用已有刷新合并器；当前刷新结束前不再重复启动完整查询，随后最多追加一轮。旧库会话、旧查询和旧画布不得收到迟到回写。
- 刷新仍保留筛选、反选、选择、全屏预览与滚动位置；前台首屏不等待慢侧栏计数。通知静音只影响提示，不吞掉实际数据变化。

## 后台任务与更新可靠性

- 导入确认过期后的文件清理失败被记录，不能作为未捕获异常终止 Library Worker；已过期的导入不会因此重新有效。
- 插件下载增加实收字节预算，并贯通暂停、取消和超时清理；失败或取消后不继续尝试其他来源，不删除原插件。
- 3D/文档渲染 RPC 各种终态只结算一次，清理定时器与监听器；转换等待结束后再次核对取消状态。
- 浏览器扩展上传暂存文件在对应 Worker 真正结束后才释放，不把客户端断开或请求超时误当成后台已停止。
- 延期安装更新在恢复与实际启动前校验下载产物；没有可信记录的旧缓存要求重新准备。保留进度结束后自动打开软件的体验。

## 构建与兼容

- 门禁清单统一维护，区分通过、失败、跳过、未运行和缺失能力。
- 构建记录绑定版本、平台、源码/资源输入及实际包文件；安装器、完整 ZIP、增量包和校验和由同一份本版附件清单选择，避免把历史产物混入新发行。
- 保留原数据库 schema49、外键、事务、租约、FULL 持久性及验证备份恢复策略；本次不进行数据库迁移，不改变外部链接文件夹的删除权限。

没有用小型测试推导大图库速度提升百分比；真实 NAS、超大插件包及线上 AI 的性能测量不在本次结论中。详细验收以本版验证记录为准。
