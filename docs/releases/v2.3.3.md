# Super Lib v2.3.3

## 本版重点

- 将资源库切换器迁移到导航栏左下角，采用类似 Obsidian 的资源库工作区布局。
- 左下角资源库卡片支持亚克力透明背景、背景模糊和路径显示，并保留创建、打开、最近资源库、同步与资源库设置等操作。
- 无资源库启动页改为“最近资源库 + Super Lib 操作区”的双栏布局。
- 关于窗口补充产品信息卡片与开源反馈提示，自动更新流程保持不变。

## 更新交付

本版沿用增量优先、完整包回退、断点续传和 SHA-256 校验规则。ECS 保留最近 5 个完整发行目录及最多 20 个增量来源版本；GitHub Release 与 ECS 使用同一组发行产物。
