# Super Lib v2.3.0

## 文件夹新建目标更清晰

- 左侧“文件夹”标题现在支持点击，并具有悬停、选中及键盘焦点反馈，自动适配深色和浅色主题。
- 点击标题文字或其后的空白区域，只将后续新建文件夹的父级切回资源库根目录；当前浏览目录、打开的图片预览和鼠标点击前的键盘焦点保持不变。
- 标题旁的显示忽略项、“+”和链接按钮仍独立执行原有功能。
- 移除双击标题栏切换新建目标的行为，避免与系统最大化/还原操作冲突；拖动窗口不会改变新建目标。
- 同步更新中英文使用说明。

## 自动更新

沿用现有断点续传、SHA-256 校验、增量优先与完整包回退机制。发布时从保留的历史基线生成直达本版的增量包；超过完整包 60% 的增量不分发。ECS 保留最新 5 个完整发行目录，最多保留 20 个增量来源版本。ECS 与 GitHub 分发相同版本产物。
