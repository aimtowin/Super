# Super Lib v2.3.7

## 本版重点

- 资源库切换菜单中的“关闭资源库”改名为“资源库索引”，实际操作逻辑保持不变。
- 新增 SolidWorks 原生文件识别：`.sldprt`、`.sldasm`、`.slddrw` 可使用格式筛选与后缀默认缩略图。
- SolidWorks 文件预览页提供系统关联打开入口；安装并关联 SolidWorks 或 eDrawings 后可直接打开源文件，未关联时给出明确提示。

## 更新交付

本版沿用增量优先、完整包回退、断点续传和 SHA-256 校验规则。ECS 保留最近 5 个完整发行目录及最多 20 个增量来源版本；GitHub Release 与 ECS 使用同一组发行产物。
