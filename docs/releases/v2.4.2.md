# Super Lib 2.4.2

日期：2026-11-12。平台：Windows x64。

本版是性能与启动体验版本，功能范围不变。

## 主要改动

- 启动生命周期重排：窗口先显示，Library Worker 握手、全局插件激活和最近资源库恢复改为并行；渲染层首次 `listOpen` 仍等待恢复完成，不出现空库竞态。
- 50k 级资源库布局减负：justified/masonry 复用已计算的 rows/columns，避免每个分页块重复计算。
- 3D/PDF 查看器改为按需加载（`lazy` + `Suspense`），首屏不再预加载 3D 场景代码。
- 智能合集查询纳入交互浏览命令，恢复后切换智能合集时磁盘维护会让出交互窗口。

## 验证摘要

- `npm run typecheck`、`npm run lint` 通过。
- 全量单元测试通过（2.4.2 构建前：450 文件 / 3614 通过 / 5 跳过）。
- 启动 A/B（生产型 E2E，热缓存，n=2）：窗口 2336.5 → 662.5 ms，库可用 2787.5 → 2254 ms。
- 布局 A/B（50k 条目）：50k 库 100 个分页块累计 804.0 → 403.5 ms。
- 3D 查看器 E2E 3 项、PDF 多页 E2E 1 项通过；5k 资产浏览 E2E 通过。
