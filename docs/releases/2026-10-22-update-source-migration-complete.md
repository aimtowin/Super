# Super Lib 更新源迁移完成公告

宣布日期：2026-10-22　状态：**已完成**

## 1. 结论

Super Lib 的自动更新功能已从旧域名整体迁移至新服务器（`https://43.142.93.106`），并完成端到端验证：新源下发清单、增量包下载与 SHA-256 校验、客户端安装并自动启动新版本的闭环均已实测通过。2.4.1 是本次迁移后的首个正式发行版本。

## 2. 完成范围

| 环节 | 状态 |
| --- | --- |
| 服务器 | 新服务器 `43.142.93.106` 提供 `/downloads/super/`（HTTPS + IP 证书），清单与静态文件直出 |
| 客户端 | 更新源常量已切换并随 2.4.0 起发行；仍强制 HTTPS + SHA-256 校验 |
| 清单与增量 | `latest.json` 指向 2.4.1，含 2.4.0 → 2.4.1 增量（约 2 MB） |
| 端到端 | 2.4.0 安装版实测自动升级到 2.4.1 成功 |
| 发行渠道 | 新服务器与 GitHub Release（v2.4.0、v2.4.1）同步提供产物 |
| 旧源与旧资产 | 旧域名入口停用；旧版本、增量包与安装包已按策略清理 |

## 3. 对用户的影响

- **2.4.0 及更新版本**：无需任何手动操作，继续自动更新，通常只下载增量包。
- **2.3.21 及更早版本**：旧域名入口已停用，需要手动下载并覆盖安装一次 2.4.x；覆盖安装不会删除资源库、素材与设置，完成后自动更新即恢复。

## 4. 后续安排

- 更新源暂以服务器 IP 直连（域名备案未完成），证书由服务器定时任务自动续期。
- 后续版本按既有流程发布：增量优先，增量不可用时安全回退完整包。

详细技术证据见 [2.4.1 验收记录](v2.4.1-validation.md) 与 [2.4.0 验收记录](v2.4.0-validation.md)。
