# Super Lib 2.3.19

## 本次更新

- Markdown：源码／渲染切换，卡片与检查器结构预览；支持表格、任务列表、代码与长文。保留文本草稿、保存与冲突校验，禁止执行 HTML 和隐式加载远程图片。
- ZIP：筛选成员路径，只读查看文本、Markdown 与受预算保护的图片；不解压到磁盘、不执行文件。校验成员路径、加密、符号链接、重复项、CRC、压缩比和图片解码像素。
- 文件夹封面：右键「设置文件夹图片封面」，搜索并选择库内图片、恢复默认；缺失、删除或失效缩略图自动回退，不改源图片。
- 缺失链接：设置 → 浏览可隐藏缺失链接资产和文件夹，默认关闭；开关可逆，分页、选择与布局规则一致，不更改忽略或删除记录。
- 原生文件选择：打开／导入／另存为共享最近成功目录；取消不覆盖，明确路径优先，另存为文件名保留。
- 视频封面：新生成海报优先取时长 25% 帧，短片、未知时长或空输出有界回退；不批量重建旧封面，不改源视频或代理。
- 查看器工具栏：默认靠近工具栏或窗口边缘显示；保留闲置隐藏与始终显示，键盘和焦点可达；视频隐藏主控件时保留细进度。

## 关联修复

全屏上一张／下一张保持全屏宿主；查看器 Delete 只处理当前资产，托管 Shift+Delete 保留危险确认，链接源不开放该永久删除键。修复序列滑块零帧 Home 不暂停的竞态、通知遮挡查看器工具栏、窄工作区顶部控件伸入检查器、关闭缺失链接隐藏后列表未重查等问题。

发布回归额外修复：旧库缺少缩略图状态字段时，文件夹封面查询安全回退；双击标签跳转时，不再等待不存在的预览而被后台刷新抢先取消导航。

标签管理与插件视图不再启动资产框选；按钮、输入等交互控件保持自己的鼠标事件，小于 5 像素的空白点击也会正确退出框选样式。

标签管理保留固定高度的选择状态区，窄窗口首次点击不再使工具栏换行、将标签移离第二次点击位置；双击浏览保持稳定。

导入结束后的延迟定位不再覆盖用户刚选中的资产；主动选择或打开资产右键菜单会取消待执行的批量选择与定位，避免检查器切回批量状态或菜单被后续定位滚动关闭。

## 升级边界

数据库追加迁移 52；升级前备份资源库，不用旧版继续写入新 schema。封面随完整资源库数据库保存，不属于资产级 WebDAV 元数据同步。历史媒体组件失败通过「刷新磁盘变化」重试，保留打开库不全量重扫的性能策略。

本版不修复原已知 Console 缺 TypeScript 依赖问题，见[已知问题](https://github.com/aimtowin/Super/blob/main/docs/reference/known-issues-2.3.18.md)。Windows 隔离验收不替代 macOS、NAS 压力、真实 AI 或 WebDAV 多写者验收。本体继续 MIT、免费免账号；账号／社区／官方目录与 ECS 迁移保持暂停，仅更新既有发布源。
