# Super Lib v2.3.1

## 悬浮图片预览

- 图片查看器底部新增“悬浮预览”。点击后，主窗口最小化，当前图片在无边框、始终置顶的独立窗口中打开。
- 悬浮窗口可自由移动和调整大小，图片始终按比例适配；关闭悬浮窗口后主窗口自动恢复。

## 查看器与悬浮说明

- 查看器底部操作栏上移，避免贴近窗口底缘；右侧工具说明改为向上显示。
- 色彩空间下拉菜单在深色和浅色主题下均使用可读的前景与背景色。
- 所有已有悬浮说明都会额外在应用右下角显示独立气泡：既支持工具栏的自定义说明，也支持侧栏、素材名称等原生标题提示；鼠标附近原有提示保持不变。

## 自动更新

沿用已发布的增量优先、完整包回退、断点续传和 SHA-256 校验规则。发行时从可保留的历史基线生成直达 v2.3.1 的增量包；ECS 保留最新 5 个完整发行目录及最多 20 个增量来源版本，GitHub Release 与 ECS 使用相同产物。
