# Super Lib 2.4.8

日期：2026-11-18（Asia/Shanghai）。平台：Windows x64。

本版交付首个“图片素材生成”拓展，并修复插件 iframe 的加载占位层竞态。

## 主要改动

- **图片素材生成**（`com.super.image-studio` 1.0.0）
  - 侧栏“拓展”下方的同名入口，打开完整工作台。
  - 画面描述、固定模型 `gpt-image-2.6`、尺寸预设与自定义尺寸（256–4096，宽高需为 16 的倍数）、一次生成 1–4 张。
  - 结果预览、下载原图、最近生成历史。
  - 安装无需鉴权；生成与读取历史需要唯一访问密码，密码只保存在当前工作台页面内存中。
  - 上游网关密钥保存在 Super 服务器代理，不进入拓展包或浏览器页面；代理带限流与短时下载令牌。
- **插件 iframe 修复**：插件在 iframe load 事件前发送 `plugin-ui.ready` 时，宿主的加载占位层不再永久覆盖可用页面。
- 服务器拓展目录现有：
  - `com.super.infinite-canvas` 1.0.0（最低 2.4.6）；
  - `com.super.image-studio` 1.0.0（最低 2.4.8）。

## 升级方式

- 2.4.0 / 2.4.1 / 2.4.2 / 2.4.4 / 2.4.5 / 2.4.6 / 2.4.7 客户端均可增量升级。
- 2.3.21 及更早版本仍需手动安装一次 `SuperSetup.exe`。
