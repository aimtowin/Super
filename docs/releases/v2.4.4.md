# Super Lib 2.4.4

日期：2026-11-17（Asia/Shanghai）。平台：Windows x64。

本版是稳定性与窗口体验版本，包含 2.4.3 未发布工作中的窗口状态记忆，以及修复托盘恢复/手动刷新导致的 Worker 全局卡死问题。

## 主要改动

- **刷新稳定性**：手动刷新改为异步、可让出、可取消、按库单飞的任务；刷新期间 Worker 仍可处理浏览、搜索和状态查询，不再因同步全量扫描阻塞事件循环。
- **托盘恢复**：暂停期间保留待对账库和 watcher 脏 scope；恢复延迟期间再次暂停不会丢失对账，恢复后会重新调度。
- **缩略图维护**：从手动刷新响应链移除全量缩略图修复，刷新完成后只执行有界场景，避免全表修复查询再次独占 Worker。
- **超时策略**：清理无效的长操作集合；`asset.refresh` 保持无界语义，不再用延长 deadline 掩盖实际阻塞。
- **窗口状态记忆**：记住窗口位置、尺寸和最大化状态；启动时校验显示器工作区与最小尺寸；设置 → 通用中可关闭，默认开启。

## 升级方式

- **2.4.0 / 2.4.1 / 2.4.2 客户端**：可从更新源增量升级，本版提供对应直达增量包。
- **2.3.21 及更早版本**：旧更新源已下线，需手动安装 `SuperSetup.exe` 一次；覆盖安装不删除资源库、素材与设置。
