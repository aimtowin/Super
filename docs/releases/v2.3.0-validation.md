## 完整单测并非全绿

全套结果：4073 项通过、39 项失败、25 项跳过（463 个文件通过、11 个文件失败、14 个文件跳过）。未修改的主线提交 `7e0c3ba`（2.2.8）在隔离对照工作区中复现了这 39 项失败：10 个测试文件 21 项失败，另一个 trash-relink 文件 18 项失败。

已确认的旧预期/环境差异包括：

- 迁移快照仅列到 v45，而现有实现已经包含 v46–v49；这不是本次改动修改了已发布迁移。
- 文件夹结果新增 autoAiAnalysis 字段，但旧测试仍逐对象严格匹配旧字段集合。
- 合集布局旧测试期望一次返回 20000 条，现有分页结果返回 500 条。
- 现有样式的一处白色常量触发主题 token 检查，与本次仅使用主题变量的新标题样式无关。
- 本机精简 FFmpeg 不包含媒体造数测试依赖的 lavfi；若干重链/缺失资源状态和 Windows 清理断言也可在旧提交复现。

因此不能把 verify:mainline 记为通过。本次保持修复范围，不通过修改历史迁移、屏蔽测试或刷新快照来掩盖这些失败。完整测试的维护债务应单独处理。
