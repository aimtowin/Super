# v2.3.8 验证记录

## 变更范围

- Forge copy filter 仅裁剪三个内置字体包的原始字体/CSS，以及 cn-font-split、woff-build 的构建工具载荷。
- 保留 Vite 正式字体及许可文件，不裁剪 Electron locales、React、Three、PDF.js、QuickJS、SQLite、Canvas、Sharp、媒体工具。
- 安装器仅在应用安装目录清理 6 个明确的字体相关包目录，随后复制本版元数据和许可证；不清理用户素材路径。增量包沿用删除清单。
- 纳入此前已完成的快速开始引导及中英文文本，已有资料库用户不被自动打断。

## 已通过

- `npm run typecheck`、`npm run lint`。
- 清理、字体门禁及媒体单元测试：45 通过、5 跳过（媒体测试的平台条件）；跳过不记为通过。
- 更新选择与保留策略单元测试：25 通过。
- `npm run release:package`：本机原生依赖/媒体来源验证及成品检查通过；528 处字体引用与三份字体许可证完整。
- 成品启动：真实创建/导入、FTS5 搜索和关闭到托盘通过；实际加载三种内置字体，非仅依赖系统字体回退。
- 成品专项：PDF 主预览及悬浮窗、OBJ+MTL 解析、FBX 转换预览、快速开始完整流程及跳过持久化，5 项通过。
- 快速开始包含深/浅色、最大字号、640×480 和 360×340 窗口、焦点循环、设置返回和已有用户升级不弹出断言。
- 最终成品组合回归：8 项全部通过（29.4 秒）。
- 首轮引导成品测试误用了开发专用对话框路径环境变量；改为通过 Playwright 控制测试实例的原生文件选择结果后复测通过，未修改产品逻辑以绕过验证。
