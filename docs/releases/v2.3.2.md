# Super Lib v2.3.2

## PDF 悬浮预览

- PDF 查看器操作栏新增“悬浮预览”。点击后，主窗口自动最小化，当前 PDF 在无边框、始终置顶的独立窗口中重新加载。
- 悬浮 PDF 保留按页滚动、缩放、适应和拖动平移；浮窗可自由移动和调整大小。关闭浮窗或按 `Esc` 后，主窗口自动恢复。
- 悬浮窗口的权限仍只限于 Main 已授权的 `super://` 图片或 PDF 预览地址；视频、音频和 3D 文件不会获得该入口。

## 自动更新

沿用已发布的增量优先、完整包回退、断点续传和 SHA-256 校验规则。本版从保留基线生成直达 v2.3.2 的增量包；ECS 保留最新 5 个完整发行目录及最多 20 个增量来源版本，GitHub Release 与 ECS 使用相同产物。
