# Super Lib 2.4.1 更新公告

发布日期：2026-10-22。本版是更新源迁移后的首个自动更新验证版本，功能与 2.4.0 相同，重点说明 2.3.21 的性能改进与 2.4.0 的更新源切换。

## 一、2.3.21：把"切换文件夹"真正做快

2.3.21 的主线是文件夹导航的加载顺序与查询范围，用户能直接感知的变化：

| 改进 | 以前 | 现在 |
| --- | --- | --- |
| 首屏顺序 | 切换目录时右侧统计/封面与中央画布抢同一批 Worker/SQLite 查询 | **中央资产卡片优先绘制**，右侧统计与封面随后独立读取，不再拖住画面 |
| 右侧检查范围 | 为了一个目录的信息，会枚举整库目录列表，链接目录还会遍历多个来源树 | 改为**只读目标目录/链接根索引**，并去掉封面查询用不到的精确计数，减少无关磁盘与数据库读取 |
| 空状态判断 | 查询还没回来就显示"导入"空提示，像目录真的空了 | 读取中显示加载动画，**只有查询成功且确实没有资产/子目录**才显示导入提示 |
| 重复请求 | 清空筛选、恢复排序会触发重复首屏请求；旧 debounce 会覆盖新目录 | 语义等价的筛选重置不再触发新查询，过期请求不会覆盖新导航 |
| 遗留状态 | 快速切换或同 ID 重开后偶发一直"加载中" | 旧结果与 loading 状态按导航代次隔离，切换后不再残留 |

同时保留了筛选、合集、封面、递归数量、Unicode 路径、链接目录离线信息与全屏后台刷新等既有行为；没有重建用户索引，也没有修改资源库数据。

说明：具体快多少取决于磁盘类型、素材库规模与目录结构，本节不承诺固定百分比或所有 NAS 场景的统一速度。

## 二、2.4.0：更新源改为服务器 IP 直连

新服务器域名尚未完成 ICP 备案，旧更新地址也不再稳定，因此 2.4.0 把自动更新源从域名切换为服务器 IP 直连：

```
https://43.142.93.106/downloads/super/latest.json
```

服务器已为该 IP 签发受信任证书，安装包仍走 HTTPS 并做 SHA-256 校验。

**对用户的影响只有一次**：

- **2.3.21 及更早版本**：客户端里写死了旧更新地址，已经无法自动发现新版本，需要**全量下载一次 2.4.1 安装器**（`SuperSetup.exe`）覆盖安装。覆盖安装不会删除资源库、素材或设置。
- **2.4.0 及以后版本**：自动更新恢复正常；本版已提供 `2.4.0 → 2.4.1` 的增量包（约 2 MB），后续版本也会继续提供增量更新，不必再次全量下载。

## 三、本版（2.4.1）内容

- 验证 IP 直连更新源的完整链路：检查清单 → 下载 → 校验 → 安装 → 自动打开。
- 恢复增量包机制：2.4.0 用户升级仅需约 2 MB 增量包。
- 无功能性改动；若你已在 2.4.0，升级后界面与功能保持一致。

## 四、升级方式

| 当前版本 | 操作 |
| --- | --- |
| 2.3.21 及更早 | 下载并运行 `SuperSetup.exe`（全量，一次即可） |
| 2.4.0 | 启动后按左下角更新提示操作，自动使用增量包 |
| 2.4.1 | 已是最新 |
